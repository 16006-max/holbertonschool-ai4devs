# User Stories - TaskMaster AI

## User Story 1
As a startup founder, I want to create a new project workspace with a title and description so that I can organize my sprint tasks in one place.

## User Story 2
As a project manager, I want to paste raw feature requirements into an AI generator input so that the system automatically breaks them down into actionable tasks.

## User Story 3
As a team lead, I want each generated task to include a suggested priority level (Low, Medium, High) and estimated hours so that I can plan sprint capacity accurately.

## User Story 4
As a user, I want to manually create, edit, or delete tasks on my board so that I have full control over task details.

## User Story 5
As a developer, I want to move tasks across "To Do", "In Progress", and "Done" columns on a Kanban board so that my team can track real-time progress.

## User Story 6
As a user, I want to filter tasks by priority level or status so that I can quickly focus on urgent deliverables.

## User Story 7
As a user, I want to search tasks by keyword in real time so that I can locate specific items without scrolling through the entire board.

## User Story 8
As a startup founder, I want to view a lightweight sprint summary showing total tasks, completed tasks, and remaining estimated hours so that I can monitor velocity.

## User Story 9
As a project manager, I want to export the current project board as a JSON or CSV file so that I can share progress reports with stakeholders.

## User Story 10
As a user, I want clear visual feedback (success toasts and error alerts) when creating, updating, or exporting tasks so that I know my actions were saved properly.
