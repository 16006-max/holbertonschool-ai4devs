# User Stories - AI Sprint Retro & Blocker Analyzer

## User Story 1
As a team member, I want to submit a quick daily check-in (Yesterday, Today, Blockers) through a simple form so that I can share my status in under 30 seconds.

## User Story 2
As a team lead, I want the AI engine to automatically scan submitted check-ins and detect hidden blockers or cross-team dependencies so that risks are caught early.

## User Story 3
As a scrum master, I want each detected blocker to be assigned a severity level (Low, Medium, High, Critical) so that the team knows which issues require immediate attention.

## User Story 4
As a developer, I want the AI to suggest concrete, actionable resolution steps for my reported blocker so that I can unblock my work faster.

## User Story 5
As a project manager, I want to view a live team health dashboard showing sprint momentum, active blockers, and resolved issues so that I can monitor overall hackathon progress.

## User Story 6
As a team member, I want to mark a blocker as "Resolved" with a short resolution note so that the dashboard reflects real-time progress.

## User Story 7
As a team lead, I want to filter check-ins and blockers by team member, date, or severity level so that I can focus on high-priority bottlenecks during standups.

## User Story 8
As a hackathon participant, I want to export the daily AI sprint summary as a formatted Markdown report so that I can paste it directly into Slack, Discord, or GitHub.

## User Story 9
As a user, I want clear visual feedback (loading indicators and confirmation alerts) when submitting updates or generating AI analysis so that I know the system is processing my request.
